# sepulcrito

Web de Sepulcrito. De momento, la home: intro (blanco → estrella → foto → zoom) y landing rosa.

- `index.html`, `css/style.css`: todo; se lee sin JS, el JS solo deja saltar la intro.
- `assets/img/home.webp`: foto de fondo (L0rna, `PS5A7405`). `star.webp`: la estrella, recortada
  del mockup con `tools/estrella.py`.
- `fonts/`: Anton y Pinyon Script (OFL), woff2 propias, sacadas a ojo de los mockups de la landing.

El [Figma](https://www.figma.com/design/UzpXb67tEoMRwDicfpqLYy/sepulcrito) es el boceto de octubre de toda la web
(welcome, home con el menú en los cuatro bordes, art rosa, comercial blanco, tattoo rojo, proyectos en
scroll horizontal); la landing no está ahí: sale de `landing refes ideas` (noviembre).

Pendiente: obra, about, dirección creativa, tattoo; build a `dist/` como el resto del estudio.
